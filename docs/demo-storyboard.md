# Verify-first handoff demo storyboard

Target length: 30–45 seconds. Everything shown comes from the shipped `proof` command. The demo uses a synthetic prior-agent claim, a throwaway git repo, and a temporary memory workspace; it contains no recording of a real user, agent session, or project.

Run from a cloned repository:

```bash
bash examples/verify-first-handoff-demo.sh
```

Do not paste a prepared output block into the recording. Record the command's live output so the commit IDs, paths, timestamps, and audit ID are generated by that run.

| Time | Frame | Point to evidence that actually appears | Permitted narration |
| --- | --- | --- | --- |
| 0–5s | Start with the command visible. | `cloud: disabled / local only` and temporary isolation lines. | “This runs locally in disposable workspaces with synthetic data.” |
| 5–13s | Hold on the prior handoff. | `prior narrative: UNVERIFIED` and recorded/live HEAD. | “The previous agent's claim is not accepted as fact.” |
| 13–22s | Let both verdicts appear. | `GREEN` before drift, a different live HEAD, then `RED`. | “Matching live git anchors can earn GREEN; later drift forces RED.” |
| 22–34s | Move to governed local memory. | Agent A candidate and promoted paths; agent B search hit and citation. | “One agent proposes; governance promotes; another agent finds the same cited Markdown.” |
| 34–42s | End on audit and PASS. | `audit event:` and the final `PASS proof:` line. | “The handoff is cited and audited. The narrative itself never became verified.” |

## Claim boundary

This demo proves one deterministic local path: an unverified synthetic narrative, git-anchor re-check before and after drift, and governed write → promote → search → read with a citation and audit event. It does **not** prove semantic retrieval quality, production readiness, every runtime's lifecycle integration, recovery from every crash shape, or that narrative text is factually true. The runtime matrix in the README is the source for per-host maturity.

For a real two-application walkthrough, use [flagship-cross-tool-handoff.md](../examples/flagship-cross-tool-handoff.md), disclose the runtimes and versions being shown, and show their live responses rather than scripting a desired answer.
